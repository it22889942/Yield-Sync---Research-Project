====================================================
HOW TO RUN
====================================================

1. Train models:
   python train.py --input fertilizer_recommendation_dataset.csv

2. Start API server:
   python app.py
   (Runs on http://localhost:5003)

3. Models saved to:
   outputs/<timestamp>/best_classifier.joblib   <- Fertilizer_Type prediction
   outputs/<timestamp>/best_regressor.joblib    <- Fertilizer_per_acre prediction
